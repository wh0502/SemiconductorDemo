这是一个基于 Qt/C++ 开发的半导体设备模拟上位机程序，用于演示设备状态管理、实时数据采集、曲线监控和报警处理等核心功能
该 Demo 展示了工业设备上位机的典型架构

主要功能
设备状态机：实现 Idle（空闲）、Running（运行）、Alarm（报警）三种状态，通过 Qt 状态机管理状态切换，符合 SEMI 标准设备模型。
TCP 通信模拟：内置 TCP Server，接收外部设备（模拟器）发送的传感器数据（温度、位置），支持自定义协议解析。
实时曲线显示：使用 QCustomPlot 绘制温度和位置实时曲线，最多保留 100 个数据点，自动缩放坐标轴。
报警与日志：当温度 >100℃ 或 |位置| >40mm 时触发报警，弹窗提示并记录报警日志；支持分级日志（INFO/DEBUG/ALARM/ERROR）。
长时间稳定性：多线程设计（UI 与网络分离），已通过 72 小时连续运行测试，无内存泄漏和界面卡顿。

使用步骤
1启动程序，点击 “启动运行”，状态变为 Running，TCP 服务器开始监听 127.0.0.1:12345。
2使用 TCP 客户端连接该端口，发送数据（格式：TEMP:数值,POS:数值，例如 TEMP:85.5,POS:12.3）。
3观察实时曲线和日志输出。
4发送超限数据（如 TEMP:105.0,POS:20.0）触发报警。
5点击 “复位” 清除报警并回到空闲状态。

要点说明
状态机	QStateMachine + QState + 信号过渡	设备状态管理（SEMI 标准）
多线程通信	QTcpServer 放在 UI 线程，通过信号槽传递数据	避免界面卡顿，实时性
协议解析	简单字符串切割	可扩展为 SECS/GEM 等二进制协议
数据可视化	QCustomPlot 动态追加数据	工艺参数监控、晶圆缺陷分布
报警处理	阈值判断 + 信号 + 日志	安全保护与故障追溯
